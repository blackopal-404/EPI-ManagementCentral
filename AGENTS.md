# Safety Gear Hub — development notes

This repository is intended to run independently on a local Node.js environment and on external hosting.

## Working rules

- Keep the application independent from any hosted IDE or vendor-specific runtime.
- Prefer the existing Component → Service → Mock Data architecture for V1.
- Do not edit `src/routeTree.gen.ts` manually; it is generated by TanStack Start.
- Validate changes with `npm run dev` and `npm run build` before considering a feature complete.
